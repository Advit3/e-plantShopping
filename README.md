# e-plantShopping — Paradise Nursery

**e-plantShopping** is the Paradise Nursery online plant shop, built with React, Redux Toolkit, and React Router. Browse a curated collection of houseplants, learn about the nursery, and manage a shopping cart with live quantities and totals.

## Features

- A responsive landing page with a nursery introduction and a clear **Get Started** action.
- An About Us page describing the company and its approach to helping people grow at home.
- Eighteen houseplants organized into three categories.
- Add-to-cart controls that disable after an item is added, plus a live cart count in the shared navigation.
- A shopping cart with quantity controls, item removal, line totals, a cart total, and a “Coming Soon” checkout notice.
- Redux Toolkit state management and React Router navigation.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Product photographs are served from Unsplash and require an internet connection.
